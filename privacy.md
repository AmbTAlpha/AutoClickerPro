# Politique de confidentialité — AutoClicker Pro

**Dernière mise à jour : 12 octobre 2026**

## Collecte de données

AutoClicker Pro **ne collecte aucune donnée personnelle**. 

L'application :
- Ne demande aucune information personnelle (nom, email, téléphone...)
- N'envoie aucune donnée vers un serveur externe
- Ne collecte aucune statistique d'utilisation
- Ne partage aucune information avec des tiers

## Données locales

L'application enregistre uniquement **en local sur votre ordinateur** :
- Vos profils de configuration
- Vos préférences (thème, langue, etc.)
- Vos statistiques d'utilisation

Ces données sont stockées dans le dossier :
`%APPDATA%\AutoClickerPro`

Elles ne quittent **jamais** votre ordinateur.

## Communications réseau

La seule communication réseau est la **vérification de mise à jour** via HTTPS vers GitHub (github.com). Aucune donnée personnelle n'est transmise, seuls :
- Le numéro de version actuelle de l'application
- Une requête anonyme de lecture d'un fichier public (`version.json`)

## Vos droits

Vous pouvez à tout moment :
- Supprimer toutes vos données en effaçant le dossier `%APPDATA%\AutoClickerPro`
- Désactiver les mises à jour automatiques dans les réglages

## Contact

Pour toute question : [créer une issue sur GitHub](https://github.com/AmbTAlpha/AutoClickerPro/issues)

## Modifications

Cette politique peut être mise à jour. La date en haut indique la dernière modification.
